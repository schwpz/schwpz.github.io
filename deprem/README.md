Kandilli-only, near-live Marmara sismisite izleme paneli.

- Kandilli API aynası: `https://api.demirhanomerdemir.com/Deprem/KandilliRasathanesi?limit=1000`
- Live polling: 30 saniye
- GitHub archive: son 1000 kayıt, yaklaşık 5 dakikada bir
- Swarm detector
- Gerçek r90 swarm alanı
- Migration vector + along-strike migration
- Depth migration
- Kandilli-only b-value
- Magnitude acceleration / quiescence
- Locked-depth overlap
- Historical analogue scoring with benign/null controls
- M4+ browser sound + notification
- GEM Active Faults geometry

Bu uygulama erken uyarı veya deprem tahmin sistemi değildir.
