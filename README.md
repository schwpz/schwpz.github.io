GeoStrike
Real-Time Global Event Intelligence

GeoStrike is a real-time intelligence dashboard designed to display global events through a single operational interface.

The project brings together an interactive map, a live incident feed, dynamic statistics, and event-driven updates. It was created as an exploration of scalable front-end architecture, information hierarchy, and real-time data visualization.

Key Features
Interactive global map
Live incident feed
Dynamic statistics
Event-driven updates
Operational dashboard interface
